DC.3D.LAB — SITE

ARQUIVOS
- index.html: estrutura do site
- styles.css: visual e responsividade
- script.js: catálogo, filtros, carrinho e envio do pedido pelo WhatsApp
- assets/: imagens incluídas

PUBLICAÇÃO NO NETLIFY (repositório GitHub)
1. Extraia o ZIP no computador ou celular.
2. No repositório dc3dlab-site do GitHub, escolha Add file > Upload files.
3. Envie o conteúdo desta pasta (index.html, styles.css, script.js, README.txt e a pasta assets).
4. Faça Commit changes na branch main.
5. No Netlify, selecione o repositório dc3dlab-site. Para este site estático, deixe Base directory, Build command e Publish directory vazios. Functions directory pode permanecer no valor padrão.
6. Clique em Deploy.
